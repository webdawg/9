# The Whole Time

A picture book, in the browser. High in the canopy, a young ape named Little Mo
falls to the forest floor and has to find the way home — through scary, bad,
good, friendly, and challenging encounters — before discovering, in a moment of
real danger, that their parent Koba was watching over them the entire time.

Flip through it page by page with the on-screen arrows, the arrow keys, or a
swipe.

## Reading it

Open `index.html` in any browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```

then visit `http://localhost:8000`.
